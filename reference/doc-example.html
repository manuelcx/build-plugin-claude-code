Build your first website by talking to an AI

You describe what you want in plain words. An AI called Claude writes the code, saves the files, and fixes its own mistakes. You look, react, and ask for changes.

Who this is forAnyone who has never written code
What you getYour own website, live on the internet
What you needA computer, an email, a paid Claude plan

How to read this: look at the pictures first. Then follow sections 03 to 09 in order, one at a time. You never have to type code yourself.

01

The big picture

Your idea travels through five stops before it becomes a real website.

"Agentic coding" just means this: the AI does the work on your computer, step by step, instead of only chatting. You are the boss. Claude is the builder.

04

Install the apps

Three installs. Do them in this order.

1

VS Code

  1. Go to code.visualstudio.com and click Download.
  2. Mac: drag it into Applications. Windows: run the installer and keep clicking Next.
  3. Open it once so you know it works.
2

Git

  1. Mac: in VS Code, open the menu Terminal then New Terminal. Type git --version and press Enter. If a box pops up asking to install tools, click Install.
  2. Windows: download from git-scm.com and keep the default choices.
3

Claude Code

  1. In VS Code, click the Extensions icon on the left (four little squares).
  2. Search Claude Code. Install the one made by Anthropic.
  3. Click the new Claude icon and sign in with your Claude account.
?

If Claude asks you to install it

  1. Open Terminal then New Terminal in VS Code.
  2. Paste the line for your computer below, press Enter, then restart VS Code.
Mac terminal
curl -fsSL https://claude.ai/install.sh | bash
Windows PowerShell
irm https://claude.ai/install.ps1 | iex

What is the terminal? A window where you type commands instead of clicking. Claude uses it a lot. You will barely touch it.

06

Build your first website

A one-page personal website. Small enough to finish, real enough to show friends.

01
Make a folder

In Documents, create a folder called my-first-site.

02
Open it

In VS Code: File, then Open Folder, then pick it.

03
Open Claude

Click the Claude icon on the left.

04
Paste the prompt

Copy the message below, edit the details, send it.

Claude works
Your first message to Claude

I'm a total beginner. Build me a simple one-page personal website in this folder, using plain HTML and CSS only. Include my name (Alex Rivera), a short bio, three things I love, and a way to contact me. Make it look clean and modern, and make it work well on phones. When you're done, explain in plain English what each file does and how to open the site in my browser.

Claude will ask permission before creating files or running commands. Read what it wants to do, then click Yes. This is normal.

To see your site: find index.html in your folder and double-click it. It opens in your web browser.

07

Improve it by talking

This loop is the whole skill. You will repeat it hundreds of times.

Try saying

Make the colors warmer and the title bigger.

Try saying

Add a section with three photos. Use placeholders for now.

Try saying

Something looks broken on my phone. Can you check and fix it?

Be specific, like with a person. "Make it nicer" gets a guess. "Make the background soft blue and the buttons rounder" gets what you want.

08

Save it to GitHub

GitHub keeps a copy online. Vercel will read your site from there.

1st time

Publish the project

  1. Click the Source Control icon on the left (it looks like a branch with three dots).
  2. Click Publish to GitHub.
  3. Sign in to GitHub when asked. Choose private.
every time after

Save your changes

  1. Just tell Claude: "Save my changes to GitHub with a short note about what changed."
  2. Or use the buttons: in Source Control, type a note, click Commit, then Sync Changes.

Each save is a checkpoint. If something breaks later, you can say "go back to the last version that worked" and Claude can bring it back.

09

Put it online with Vercel

Connect once. After that, every save to GitHub updates your live site by itself.

01
Add New

On vercel.com, click Add New, then Project.

02
Allow GitHub

If asked, let Vercel see your GitHub projects.

03
Import

Find my-first-site and click Import.

04
Deploy

Leave the settings as they are. Click Deploy.

you're live

You get a real link like my-first-site.vercel.app. Send it to anyone. Later you can connect your own domain name in Vercel's settings.

10

Good habits

These are the habits that matter most in my own daily use.

Plan first

For anything big, say "make a plan first, don't build yet." Read the plan, then say go.

One thing at a time

Small requests work better than a list of ten.

Fresh start per task

Type /clear when you switch topics. Claude focuses better with a clean slate.

Save often

Every time something works, save it to GitHub. Checkpoints are free.

Ask "why"

"Explain that like I'm new to this." Claude is a patient teacher.

Give it house rules

Type /init. Claude makes a notes file called CLAUDE.md that it reads every time. Add your rules there.

Paste errors

If you see a red error, copy it into the chat. That is usually all Claude needs.

Show it pictures

Drag a screenshot into the chat: "make it look more like this."

Example house rules for your CLAUDE.md file
- I am a beginner. Explain everything in plain English, no jargon.
- Before big changes, show me a short plan and wait for my OK.
- Keep the site simple: plain HTML and CSS unless I ask otherwise.
- After each finished change, remind me to save it to GitHub.

Never put passwords or secret keys in your website files. Anything in a website can be seen by anyone. If a service gives you a secret key, ask Claude how to keep it safe first.
